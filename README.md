# html-pages

Self-contained static HTML pages, served with GitHub Pages.

One file per page. Each page inlines its own CSS and JS — no build step, no shared
assets, nothing to install. Drop a file in, commit, push.

```
git add my-new-page.html && git commit -m "add my-new-page" && git push
```

Live at <https://prajwalprashanth.github.io/html-pages/>

Add each new page to the list in `index.html` so the front door stays current.
